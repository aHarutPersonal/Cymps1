## Content-quality finding — still open

The lesson correctly calculates Lena's profit as $0 and cash increase as $350, but its explanation omits one component:

`+$500 customer deposit − $250 additional prepaid-insurance outflow + $100 collection of an opening receivable = +$350`.

The workbook inherits the missing $100 explanation. It also requests per-transaction column entry in an activity that exposes only total fields. “Clean slate” wording is ambiguous alongside the prior-period receivable.

Consequently, valid JSON, word counts, and computable answer expressions are insufficient publication criteria. Semantic review and instruction-to-field alignment still need strengthening before treating generated lessons as approved teaching material. Existing catalog publication gates and unresolved background-budget holds were retained. Earlier failed user lessons were not regenerated by this synthetic test.
