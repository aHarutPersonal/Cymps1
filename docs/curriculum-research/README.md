# Исследование учебной архитектуры CMPYS

Результат: рекомендована персональная сборка из проверенных блоков с отдельным контрактом метода наставника и оценкой реального выполнения заданий. Пять существующих промптов исправлены. Полная архитектура описана для последующего внедрения и ещё не подключена к приложению.

После исследования отдельно реализована [практика внутри приложения](PRACTICE_IMPLEMENTATION.md): сервер, сохранение попыток, проверка ответов и Flutter-экран. Большая архитектура общей библиотеки по-прежнему не внедрена целиком.

- [Аудит всех 47 файлов промптов и основных встроенных запросов](PROMPT_AUDIT.md).

- [Полноценный пример урока по owner earnings](BUFFETT_LESSON.md): вымышленные данные, самостоятельные задачи, решения, обратная связь; прогноз 48–72 минуты пока не измерен на учениках.

## Воспроизведение

Из корня проекта, без платных API и запросов в БД:

```sh
cmpys/backend/.venv/bin/python docs/curriculum-research/audit_checks.py
python3 docs/curriculum-research/cost_model.py
```

Первый скрипт использует существующие тестовые фикстуры и намеренно подтверждает недостатки отдельных проверок. После исправления реализации соответствующие ожидания и отчёт потребуется обновить. Он не является тестом того, что плохой урок опубликован. Второй скрипт рассчитывает сценарии, а не считывает фактические расходы.

Исследование основано на локальном коде и первичных публичных источниках. Производственные данные, реальные ответы моделей на сравнительном наборе и результаты учебного пилота не исследованы. Подробный план такого сравнения приведён в отчёте.
